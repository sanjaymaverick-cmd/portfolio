Human execution loop

Meridian sizes and prompts. The human executes at the broker. There is no OMS.

Sequence

  1. Fresh marks + Greeks (actionable lots mute if stale).
  2. Policies fire separately: inventory_hedge, vol_harvest, vega_defense.
  3. Explicit Acknowledge — Accept / Dismiss / Snooze.
  4. Optional intended-trade note tagged with policy_kind.
  5. Human trades at the broker. Options change vega; futures clean residual Δ.
  6. Log fills against the intent. Re-mark. New review only if still offside.

Copy rules

Use review / consider / note. Never “you should hedge”, “execute”, “buy USD”, or “must reduce”. Every review title includes “(not an order)”.

The two PnL lines

Daily PnL is what one quiet day does, mostly from time (theta). If you pay time, the number is negative. If time pays you, it is positive.

Gamma Scalping PnL is the extra from a chosen market move. Long gamma can add extra profit if leftover direction stays small. Short gamma can add extra loss. The desk never treats short gamma as an edge.

Six vega actions

  1. Stay under the vega line (shows how full the line already is).
  2. Shrink the option itself.
  3. Add an opposite or different option.
  4. Balance long and short vega across names.
  5. Tighten the line when the market mood is stressed.
  6. Let vega fall as expiry gets close.

Each action also shows the hit to Delta, Gamma, and Theta. None of them is an order.
