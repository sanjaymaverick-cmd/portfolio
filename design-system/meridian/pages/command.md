# Command Dashboard

Eight-second read. One frame, no scroll required on 1440×900.

1. **Mast** — wordmark, desk clock, as-of stamp, regime pill, advisory disclaimer.
2. **Hero strip** — Market value · Invested · Unrealised P&L ₹ · P&L % · Names / accounts. Figures left-aligned on a 5-column grid. No sparkline gimmicks in the hero.
3. **Context row** — sector weight bars · m-cap mix · portfolio β / ρ stubs · regime one-liner.
4. **Alert rail** — single 28px strip, max 3 items, gold hairline. Empty state is a quiet “No open alerts”.
5. **Book table** — the remainder of the viewport. This is the product.

Sidebar (168px) is account filter + import, not navigation chrome.
